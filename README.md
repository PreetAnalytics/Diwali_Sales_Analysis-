# Diwali_Sales_Analysis
Data analysis of Diwali sales using Python and Pandas

This project explores a retail dataset of Diwali sales to uncover insights that can help businesses make better decisions around customer targeting, product offerings, and promotional strategies during the festive season.

## 📊 Objective

The main goal of this analysis is to:
- Understand consumer buying behavior during Diwali
- Identify high-performing products and states
- Explore demographic patterns (age, gender, marital status)
- Provide actionable insights using data visualization

## 📁 Dataset

The dataset used in this project contains:
- Customer demographics (Age Group, Gender, Marital Status)
- Product categories and amounts spent
- Geographic data (State, City)
- Sales figures



## 🧠 Key Insights

- Top purchasing age group and gender
- States with the highest sales
- Products with the highest revenue
- Spending behavior based on marital status

## 📌 Tools Used

- **Python**
- **Pandas** – for data manipulation
- **Matplotlib & Seaborn** – for data visualization
- **Jupyter Notebook** – for interactive coding and visualization
